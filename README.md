# Cats
Intro to HTML 

This is a simple Intro to HTML project featuring a webpage about cats.

About the Project

The page demonstrates basic HTML concepts, including:

Headings and paragraphs
Ordered and unordered lists
Images and captions
Links
Forms
Radio buttons
Checkboxes
Text inputs
Submit buttons
Basic CSS styling
Features

The webpage includes:

An adorable cat picture
Fun facts about things cats love and hate
A cat information form
Cat age options
A link to a cat age chart
A field for submitting a cat photo URL
Technologies Used
HTML5
CSS
Purpose

This project was created to practice the fundamentals of building and styling a webpage with HTML and CSS.
